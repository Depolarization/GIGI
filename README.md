# GIGI
Genshin Impact Genius Invokation TCG Tool

Main functions
1. Query any player's Genshin Impact event homepage information
2. Retrieve information on the last ten matches and include matching opponent information for each match
3. Check the ranking of event points and peak points
4. Query the usage information of all cards
4. Query information related to the number of matches played
5. Information that can be calculated or derived by viewing the above information.

The data obtained and generated are stored locally without third-party risks, and regular use will not cause account abnormalities.
